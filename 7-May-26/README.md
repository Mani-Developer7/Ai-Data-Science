# Mega Mart Billing System

A simple **command-line shopping cart and invoice generator** built in Python.  
Users can add items (e.g., Rice), specify quantities, and receive a tax-inclusive bill.

## Features

- View available product (Rice with price & stock)
- Add items to cart with quantity validation
- Automatic cart total calculation
- Generate professional invoice with:
  - Date & time
  - Unique bill number
  - Itemized list (quantity, price, total)
  - 5% tax calculation
  - Grand total
- Simple "done" option to finish shopping
